# Editing the website

A guide for the communications team and project leads. You do not need to touch any code.

**Where:** https://chris-charis-concept.sanity.studio (the CTO sends your invitation).
**When changes appear:** within about a minute of pressing **Publish**.

## The golden rules
1. **Only publish what is verified.** Figures need a source; quotes, partners and team members need their approval.
2. **Consent first.** Every photo of a participant needs consent recorded before it can be published (the Studio will not let you publish a photo until the consent box is ticked). Stories appear only when their consent is set to **granted**.
3. **Describe every photo.** The *Alt text* field is read aloud to blind visitors: say what is in the picture in one sentence.

## What lives where

| In the Studio | Changes on the website |
| --- | --- |
| **Site settings** | Email, phone, address, social links, project website links, vision/mission/values, hero video and poster |
| **Homepage** | The *Featured now* event (title, dates, buttons) and the *Latest film* |
| **Project families** | The five project pages: intro, editions and films, results, photo gallery, buttons. Gallery photos also appear in Media → Gallery |
| **Organisations** | The five organisation pages |
| **Impact figures** | The numbers on the homepage, About and Impact pages |
| **Impact stories** | Impact → Stories |
| **Annual reports** | Impact → Annual Reports (upload the PDF) |
| **Our Story timeline** | About → Our Story |
| **News & blog** | News pages |
| **Press kit files** | Media → Press Kit downloads |
| **Team** | About → Team |
| **Partners** | Partner logos (homepage and About → Partners); tick *Permission to display logo* |

Anything you leave empty keeps the text the website already shows, so you can fill things in gradually.

## Common tasks

**Add photos to a project.** Project families → choose the project → *Gallery* → add images → write alt text and caption → tick consent → Publish. Use photos at least 2000 px wide; the website resizes them.

**Change the featured event.** Homepage → *Featured initiative* → update title, dates, description, image and up to three buttons (for example Apply, Vote, Sponsor). A button needs a full `https://` link or a page on the site such as `/get-involved/partner`.

**Publish a film.** Project families → Film for Social Change → *Editions and outputs* → open the film → paste its YouTube link → Publish. To feature it on the homepage, also set Homepage → *Latest film*.

**Update the impact figures (every quarter).** Impact figures → open each one → update *Shown as* (exactly as it should appear, e.g. `1,500+`), the number used for the count-up, the *Source* and *As of* date → Publish.

**Post news.** News & blog → Create → title, short excerpt, date, category, image, text → Publish. The address is created from the title.

**Add a story.** Impact stories → Create → fill in the story and the verified outcome → set consent to *granted* only once written consent is on file.

## Roles
- **Administrator (CTO):** everything, including people and settings.
- **Editor (communications):** create, edit and publish all content.
- **Contributor (project leads, where the plan allows):** draft content for an editor to review and publish.

## Things that are not in the Studio
Page layouts, the navigation menu and the legal pages are part of the code. Ask the CTO for those changes. Form submissions arrive by email and are stored in the database (the CTO can export them).
